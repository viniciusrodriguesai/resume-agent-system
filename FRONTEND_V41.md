# Frontend V4.1 Pro

A atualização altera somente a apresentação e a experiência de uso. O fluxo dos agentes e os resultados permanecem compatíveis com a V4.

## Principais mudanças

- identidade visual profissional e responsiva;
- três perfis de execução selecionáveis pela interface;
- perfil **Demonstração** otimizado para notebooks sem GPU;
- exemplos carregados com um clique;
- indicador circular de compatibilidade;
- painel executivo com métricas;
- filtros e cards de evidências;
- perfis de currículo e vaga reorganizados;
- recomendações em cards priorizados;
- auditoria e privacidade reunidas;
- linha do tempo dos agentes;
- central de exportação.

## Executar

```powershell
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

Para a apresentação, selecione **⚡ Demonstração** e rigor **Equilibrado**.
